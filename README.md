# カコモと学ぶ 決算チャレンジ 消防費編

加古川市 令和7年度一般会計決算「消防費」(約41.6億円)を、クイズと予算判断
シミュレーションで学べる単一HTMLファイルのPWAです。

## この款の特徴:人件費の不可視化

消防費の決算総額(約41.6億円)のうち、seika_houkokusho_r7.xlsxの事業一覧に
載っている「事業」は3件(指令システム管理事業・消防施設維持補修事業・
消防施設整備事業、合計約9.3億円)のみで、カバー率は約22%です。

支払先明細(kessan_meisai)を全て見ても記載金額は合計約10.8億円にとどまり、
残る約30.8億円(総額の74%)は明細データにも出てきません。負担金明細を精査した
限り大きな1件の支出はなく、常備消防を担う消防吏員(常勤の消防職員)の給料・
手当・共済費などの人件費が、事業別データから丸ごと除外されていることが
主因と見られます。これは教育費・総務費で確認した「委託料の中に人件費が
埋もれて見えない」問題とは逆に、「人件費そのものが事業別統計から除外される」
パターンで、横断テーマ(handoff_itaku_jinkenhi.md参照)に追記すべき事例です。

## 構成

1. **入口クイズ層**(11問、2択): 基礎知識5問(人件費不可視化ネタ含む)+
   予算vs決算3問+特別トリビア3問(指令システム更新工事の入札中止による延期など)
2. **本編シミュレーション層**: 3事業のみ。全て裁量事業として分類
   (消防組織法上、市が消防を維持する義務はあるが、個別の予算配分は市の裁量)
3. **答え合わせ層**: 未実装(他の款と同様)
